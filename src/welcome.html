Install from Chrome Web Store

Open in Chrome Web Store

Chrome itself does not allow extensions on phones. Use these browsers, then add GladiusBot from the Chrome Web Store.

Android

Lemur Browser

  1. Install Lemur Browser from the Play Store.
  2. Open Lemur and go to the Chrome Web Store.
  3. Open the GladiusBot page and tap Add to Lemur / Add to Chrome.
  4. Open Gladiatus in Lemur and turn the bot on from the extension.
Add GladiusBot
iOS

Orion Browser

  1. Install Orion Browser by Kagi from the App Store.
  2. In Orion settings, enable Chrome extensions.
  3. Open the Chrome Web Store inside Orion and add GladiusBot.
  4. Open Gladiatus in Orion and enable the bot.
Add GladiusBot
Installation

Manual install on desktop browser

Download the ZIP, extract the folder, open chrome://extensions, enable Developer mode, and load the unpacked extension.
